# 3DMakerPro Seal 3D Scanner

This is a very precise 3D scanner for small objects!

- [Product page](https://store.3dmakerpro.com/products/seal)
- Stats
	- **Accuracy:** 0.01mm
	- **Resolution:** 0.05mm
	- **Max area:** 30x30x30mm (though that's stretching it and you probably shouldn't)
	- **Color:** 24-bit

WARNING: This device has an extremely bright flashing strobe light when in use! It may not be suitable for individulals with photosensitive epilepsy.
{.is-warning}

## Usage

Here is a quick start video: https://www.youtube.com/watch?v=M-3ngp3TY0Q

### Software

To use it, you need to install JM Studio, located [on the manufacturer's website](https://forum.jimumeta.com/home/help/download.html).

NOTE: The device may or may not need to be linked to or unlinked from an account. If you run into issues with regards to this, please let Astrid know.
{.is-info}

### Plugging it in

There's a 3-way USB cable. It splits out the data into USB-A, and the power into a USB-C PD plug. 

**If you don't provide sufficient PD power to it, it will connect to your computer, but it will NOT have enough power for the lights! You MUST provide PD power!**
{.is-info}
